# 奶娃竞技场 · Nai Arena

一款类《弓箭手大作战》的俯视角手机竞技小游戏（网页版，打开链接就能玩）。
离线练习 + 排位赛（单人 / 组队），段位五档：奶鼠 → 奶蛋 → 奶狗 → 奶娃 → 奶绷。

> 状态：单机版。真联机排位（需服务器）尚未做，当前组队排位为本地机器人模拟。

## 玩法

- 左手滑动移动，右手在屏幕右侧滑动、朝滑动方向射击（电脑：WASD 移动 + 鼠标瞄准）；移动中可以射击
- 吃经验球升级，每升一级三选一加技能；吃血包回血；墙体挡子弹、草丛隐身
- 初始武器单发球；技能池含连发、散射、穿透、暴击、磁铁、穿墙弹、嗜血（伤害 12% 回血，可叠加）、跟班（奶虫 → 奶鸡 → 奶兔依次召唤，最多 3 个，环绕自动射击，伤害为主角一半、大小为主角 1/4）
- 射程 300；视野、小地图（左上角：自己绿点、敌人红点、血包白点）

## 模式

- **离线练习**：12 人（含玩家），机器人按段位分强度
- **排位赛 · 单人**：12 人混战，限时 4 分钟，按名次计分（第 1 名 +35 …… 第 12 名 −16，另有击杀 / 等级表现加分），满 100 分升一段，出战角色随段位变；无限复活，死后 5 秒重生、回 1 级、清技能、2 秒无敌
- **排位赛 · 组队**：18 人、6 队 × 3 人，可邀好友（最多 2 位），人不够自动匹配；无友伤；按队伍名次计分（+35 / +24 / +14 / 0 / −8 / −16）；阵亡后可观战队友；与已绑关系好友组队一局亲密度 +10
- 夺冠后全屏播放奶娃捧腹大笑视频（带原声），点屏幕可跳过

## 经济

- 结算：金币 (20 + 10 × 局内等级) × 20；钻石每满 5 级 +200；签到每天 +100 钻
- 复活卡 100 钻/张（仅练习），死后 5 秒内可用；改名卡 200 钻（首次改名免费，不可与已有玩家 / 机器人重名）
- 皮肤：每角色 5 普通 + 3 高级 + 2 典藏，共 50 款；皮肤只改配色 / 配饰，不改原有形象；穿戴皮肤进局，弹丸颜色、发光与拖尾特效跟着变
- 亲密道具：初心气泡 +10、吾爱小笺 +52、心心相印 +100、玫瑰誓言 +520、一生一世 +1314；亲密关系五种（恋人 / 闺蜜 / 兄弟 / 基友 / 姐妹），组队一局 +10
- 数据存在浏览器本地（localStorage `naiArenaProfile.v1`）

## 运行

直接用浏览器打开 `index.html` 即可（横屏游玩；手机需开自动旋转）。单文件版，无需服务器。
